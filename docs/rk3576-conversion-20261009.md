## Why s90

The existing RKNN evidence documents an attention surface limit of `H×W≤8192`
and an s512 experiment with CPU fallback at approximately `8840 ms`. The same
documentation also records a separately optimized s512 RK3588 delivery at
`509 ms`; therefore the experiment is not a universal statement that every
s512 artifact runs at `8840 ms`. This RK3576 work selected s90 because its
fixed-shape ONNX and conversion lineage were already available for reuse, not
because s90 is the only possible bucket. The s90 graph has a fixed total
sequence budget of 90 model tokens for state text, the user request, and
candidate labels. The application must expose this capacity and validate the
assembled input; this record does not prescribe silently truncating user input.
